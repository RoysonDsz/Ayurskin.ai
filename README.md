# 🧠 AyurSkin AI 🌿

A smart skin disease classifier that recommends Ayurvedic remedies based on image analysis using AI.

[![Watch Demo](static/images/background-main.jpg)](demo.mp4)

## 🚀 Features

- 🧬 Detects 6+ common skin diseases via image upload
- 🌱 Recommends Ayurvedic treatments for each condition
- 🤖 Powered by a Keras deep learning model
- 📁 Built with Python + Flask (or Streamlit, etc.)
- 🔒 Secure API integration using `.env` secrets

## 🖼️ Supported Diseases

- Eczema  
- Psoriasis  
- Acne  
- Vitiligo  
- Ringworm  
- Rosacea  
*(more coming soon!)*
